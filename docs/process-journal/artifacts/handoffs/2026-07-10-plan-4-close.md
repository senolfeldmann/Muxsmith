### SI-3. mkvtoolnix parity audit in all planning and decision-making

When authoring plans or design-decision memos, or resolving ANY behavioral
question (a default, a semantic, a policy), compare the proposed behavior
against mkvtoolnix-gui / mkvmerge wherever the comparison is meaningful.
Muxsmith's audience knows mkvtoolnix and expects matching behavior where it
applies; a silent divergence is a surprise to that audience.

The load-bearing distinction: mkvtoolnix is INTERACTIVE (it pre-fills smart
guesses the user reviews and corrects per file), Muxsmith is DECLARATIVE BATCH
(the profile IS the spec, no per-file review loop). So:
- mkvtoolnix's MUXING SEMANTICS and OUTPUT are parity targets to match.
- mkvtoolnix's INPUT-TIME CONVENIENCE GUESSES are NOT targets: filename-derived
  language/flags, auto-title-from-source, unique-name suffixing, and sequence
  auto-append are magic guesses that are right for an interactive tool with
  review and wrong as unseen defaults in batch (see docs/IDEAS.md 1-4).

For Plan 5 (GUI) this cuts BOTH ways: mkvtoolnix-gui's job-queue UX (states,
progress, warnings display) is now a direct parity reference for Muxsmith's
own GUI, while its per-file input-convenience guesses remain non-targets.

Method: classify each comparable decision as match / justified divergence /
genuine gap; read the mkvtoolnix source at ~/Downloads/mkvtoolnix (cite

## What core already provides for the GUI (do not redesign)

- `muxsmith_core::executor::queue::{run_queue, JobEvent, QueueOpts}`: `JobEvent` is `Serialize` (`#[serde(tag = "event", rename_all = "snake_case")]`, variants started/progress/warning/error/finished) and was designed in D13 exactly so a Tauri shell can forward it as events. `run_queue` blocks; the CLI's pattern (queue on a thread, drain the mpsc receiver live) is in `crates/muxsmith-cli/src/commands/run.rs`.
- `executor::job::{JobSpec, JobState, JobOutcome, run_job}` (Serialize where relevant), `executor::spawn::{Spawn, LiveSpawner, FakeSpawner}` (killed-flag semantics: `wait()` returns None exactly when the Killer fired, cross-platform).
